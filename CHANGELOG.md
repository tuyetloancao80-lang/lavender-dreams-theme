# Changelog

All notable changes to the "Lavender Dreams" theme will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-04

### Added
- 🌸 Initial release of Lavender Dreams theme
- 💜 Main "Lavender Dreams" variant with full intensity lavender colors
- ✨ "Lavender Dreams Soft" variant with muted, gentle colors
- 🌙 Complete VS Code UI theming including:
  - Editor backgrounds and text colors
  - Activity bar and sidebar styling
  - Terminal color scheme (16 ANSI colors)
  - Status bar and title bar theming
  - Panel and tab styling
  - Git decoration colors
  - Error, warning, and info highlighting
- 🎨 Comprehensive syntax highlighting for:
  - JavaScript/TypeScript
  - Python
  - HTML/CSS/SCSS
  - JSON/YAML
  - Markdown
  - And many other languages
- 🔮 Semantic highlighting support
- 🌺 Bracket pair colorization with lavender tones
- 💫 Interactive welcome screen with floating petals animation
- 📚 Detailed documentation and setup instructions
- 🌸 Accessibility features with proper contrast ratios
- ✨ Eye-friendly design optimized for long coding sessions

### Features
- 🌙 Gentle pastel lavender backgrounds inspired by twilight fields
- 💜 Harmonious purple color palette with low saturation
- 🌸 Perfect for evening and night coding sessions
- ✨ Dreamy, calming aesthetic that reduces eye strain
- 🎨 Two beautiful variants to match your mood
- 💫 Optimized for creative and meditative programming
- 🔮 Full semantic highlighting with magical touches
- 🌺 Carefully crafted for long coding sessions

### Color Palette
- **Primary Background**: `#2a2438` - Warm dark lavender
- **Secondary Background**: `#251f30` - Deeper panel tone
- **Tertiary Background**: `#1f1a28` - Rich base tone
- **Primary Text**: `#f8f4ff` - Ghostly white with lilac tint
- **Secondary Text**: `#e0d8f0` - Soft lavender-gray
- **Muted Text**: `#b8aec8` - Muted pastel gray
- **Lavender Accent**: `#b19cd9` - Classic lavender
- **Periwinkle Accent**: `#c9a9dd` - Gentle light purple
- **Plum Blossom**: `#dda0dd` - Plum-pink highlights
- **Misty Mauve**: `#d8b4e2` - Airy lilac
- **Dewdrop**: `#e6ddff` - Almost white with lilac tint
